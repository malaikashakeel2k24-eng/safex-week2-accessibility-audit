HOW TO USE
------------------------------------------------------------
1. index.html ko kisi bhi browser (Chrome recommended) mein open karein.
2. "Print / Download as PDF" button click karein.
3. Print dialog mein "Save as PDF" select karein.
4. Paper size: A4 ya Letter (default rakh sakte hain)
5. Background graphics: "Enabled" rakhein (colours preserve karne ke liye)

------------------------------------------------------------
CUSTOMIZATION GUIDE
------------------------------------------------------------

Company details change karne ke liye:
→ index.html mein "<header>" section edit karein

Course / Service data change karne ke liye:
→ <tbody> ke andar rows edit karein
→ Har row mein: Description, Qty, Unit Price, Total

Primary color change karne ke liye:
→ CSS mein "#1a3c6e" search karein aur apni favourite color daalein

Currency change karne ke liye:
→ "₨" ko apni currency se replace karein (e.g., "$", "€", "£")

Tax percentage change karne ke liye:
→ Totals section mein "Tax (8.5%)" edit karein
→ Tax amount bhi update karein

Discount change karne ke liye:
→ Totals section mein "Discount (10%)" edit karein
→ Discount amount bhi update karein

Address change karne ke liye:
→ Footer section mein address update karein

------------------------------------------------------------
PRINTING TIPS
------------------------------------------------------------
1. Print preview mein "Background graphics" ENABLED rakhein
   (Is se blue header aur light gray backgrounds print honge)
2. Paper size: A4 recommended
3. Margins: Default rakhein
4. Print dialog mein "Save as PDF" select karein for PDF export
